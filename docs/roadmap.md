# Delivery phases

This repository exposes navigation and typed integration surfaces for the complete platform while delivery can be released incrementally.

1. Foundation: authentication, product onboarding, branches, roles, staff, service catalog, customers, appointments, basic cash and dashboard.
2. Operations: packages/sessions, devices/rooms, analysis/consent, inventory, commission, campaigns and provider ports.
3. Experience: customer portal, multi-branch analytics, WhatsApp/payment/e-invoice adapters and richer reporting.
4. Expansion: Flutter customer/staff app, approval-gated AI recommendation provider, advanced loyalty and SaaS billing.

Real external adapters and AI model calls require a separately approved configuration and production readiness review. The current implementation intentionally supplies typed ports, preview flows and safe mock/not-configured states.
