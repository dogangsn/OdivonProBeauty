# Screens and wireframes

The visual system uses Plus Jakarta Sans, indigo/violet brand accents, neutral surfaces, light/dark themes, 8px spacing, executive KPI cards, compact filter toolbars, responsive tables, status chips and right-side create/edit drawers.

```text
+---------------- Sidebar ---------------+------------ Top bar ------------+
| Logo / branch                          | Search | theme | notifications |
| Dashboard                              +---------------------------------+
| Calendar                               | KPI | KPI | KPI | KPI             |
| Customers / Sessions / Catalog         +---------------------------------+
| Staff / Finance / Inventory            | Filters + primary action         |
| Campaigns / Reports / Settings         +---------------------------------+
| Portal / AI                            | chart or responsive data table   |
+-----------------------------------------+--------------------[drawer >]--+
```

The delivered route inventory includes sign-in/onboarding; dashboard; calendar; customers with health, skin and consent details; packages and sessions; services and pricing; devices and rooms; staff, shifts and leave; cash, payments, refunds and invoices; products, suppliers and stock count; commissions; campaigns; reports; integrations, roles, audit and KVKK settings; AI recommendation preview; and customer portal.

Desktop keeps the sidebar visible. Tablet collapses it to icons. Mobile uses an overlay navigation and converts tables to labeled cards. Drawers become full-screen sheets. Every control has a keyboard focus style, labels are never color-only, hit targets are at least 44px and live state changes use accessible announcements.
